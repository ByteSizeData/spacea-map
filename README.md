# Space-A Destinations Map

Space-A flight planning: interactive world map of 55 AMC terminals, smart route grouping, multi-stop trip planner, paperwork checklist, and the one-button autofill browser extension (in /extension).

## Pages
- index.html — world map + trip planner (same as SpaceA-Kite-Snow-Map.html)
- SpaceA-Smart-Routes.html — route explorer
- SpaceA-Paperwork.html — paperwork guide

## Extension
Load /extension unpacked via chrome://extensions (Developer mode), flip "Allow in Incognito" on its Details page.

## Hosting
GitHub Pages: repo Settings → Pages → Deploy from branch → main / root.
